🏢 Client Information

Client: Local Driving School Instructor

Industry: Driver Education and Training Services

The client provides driving instruction to students preparing to obtain their Ontario driver’s license and is seeking a modern web presence to better advertise services and manage inquiries.

🎯 Target Users

The primary target users of the web app are students who want to learn how to drive. This includes new drivers as well as individuals seeking refresher lessons or driving test preparation.

🎨 Design Requirements

  • The web app is intended to be responsive and accessible on both mobile and desktop devices
  • The web app’s design should remain on-brand and visually consistent with the client's existing marketing materials, such as by using the same color scheme as current marketing flyers

📱 Data and Functionality

The web app should manage and present the following static and dynamic information and interactive elements:

  • General information about the driving school
  • Lesson packages and pricing details
  • Instructor information
  • Contact and inquiry details

💻 Interactive Elements

  • Driving related animations to replace boring loading screens
  • Interactive and responsive calendar
  • Reponsive cost calucaltor
  • A potential booking system that allows students to request or schedule driving lessons
